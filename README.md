# Music Streaming Application

A web-based music streaming application developed during my Infosys Springboard internship.

## Features

- Music streaming interface
- Song listing and selection
- Interactive music player
- Organized song data
- Responsive web interface

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

- `index.html` – Main application page
- `project.html` – Project-related page
- `style.css` – Styling and layout
- `app.js` – Application functionality
- `data.js` – Song data

## Note

Audio files and third-party cover artwork are not included in this public repository.
